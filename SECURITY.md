# Security

Folder Watch for VLC runs entirely on your machine, has no network code and
handles no accounts or credentials. The one thing worth reporting privately
is anything that lets a crafted file or folder name make the scripts run a
command or write outside VLC's settings folder.

Report such issues through GitHub's private vulnerability reporting on this
repository rather than in a public issue. Fixes ship as a new release; there
is no fixed response time for a free project, but reports are read.
